# Academic Content, References and Engineering Standards

## 1. Content model

Organise content as:
Department → Course → Topic → Problem type → Formula/method → Worked example → Practice task.

Each item should have a stable ID, version, author/editor, review status and references.

## 2. Source hierarchy

Prefer:
1. Applicable legislation and official national standards
2. Official standards bodies and code publishers
3. Peer-reviewed papers and technical reports
4. Recognised university textbooks
5. Reputable university teaching materials

Record exact edition/year and relevant clauses/pages. Respect copyright: store metadata, original explanations and licensed excerpts rather than copying entire books or standards.

## 3. Code-dependent design

For timber, reinforced concrete, steel, bridges, highways and geotechnical design:
- Ask the user to select the governing code and edition.
- Keep code-specific factors and clauses isolated in versioned modules.
- Do not mix Eurocode, British Standard, ACI, AASHTO or local-code provisions.
- State National Annex or local amendments where applicable.
- Display the code clause/source used.
- If the applicable code is not configured, provide only clearly labelled educational analysis, not a code-compliant design claim.

## 4. Nigerian context

Support relevant Nigerian requirements and standards where verified and legally accessible. Also support selected international standards as separate configurations. Confirm current applicability and editions before publishing a design workflow.

## 5. Review workflow

Draft → technical review → test review → approved → published → superseded/withdrawn.

Safety-critical modules require review by a suitably qualified subject-matter expert before publication.
